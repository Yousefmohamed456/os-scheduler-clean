# Report

The report is [`report.pdf`](report.pdf), generated from
[`report.html`](report.html).

## Contents

- Title block with placeholders for team names, IDs, group and TA.
- The scheduling model, metrics and experimental setup.
- For each of the four test cases: input table, ACS and SJF analysis tables,
  the ACS average waiting/turnaround table for Q in {1, 2, 3, 4, 5} and CS in
  {0, 1, 2, 3}, the SJF table for the same CS values, and four graphs.
- Discussion of the ACS Tier 2 demotion trade-off between CPU utilization and
  response time.
- Supporting-material locations.

## Data and graphs

[`experiment-data.csv`](experiment-data.csv) contains every ACS and SJF run
used in the report. The 16 graphs in [`graphs/`](graphs/) are generated by
`experiments/ExperimentRunner.java`.

## Regenerate

From the repository root:

```text
javac -d out src/scheduler/*.java
javac -cp out -d out experiments/ExperimentRunner.java
java -cp out ExperimentRunner
```

This rewrites `experiment-data.csv` and the graphs. To rebuild the PDF, print
`report.html` to A4 with a browser, for example:

```text
chrome --headless=new --no-pdf-header-footer --print-to-pdf=report/report.pdf report/report.html
```
